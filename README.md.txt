 Retail Sales Performance Dashboard

 Project Overview
This project analyzes retail sales data to identify regional performance, category trends, and profitability insights using Power BI.

 Tools Used
- Power BI
- DAX
- Excel

 Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %

 Key Insights
- West region generated the highest total sales.
- May recorded peak monthly sales.
- Technology category showed strong revenue contribution.
- Profit margins vary across product categories.

Business Objective
The dashboard helps management monitor performance trends and make data-driven decisions to improve profitability.
